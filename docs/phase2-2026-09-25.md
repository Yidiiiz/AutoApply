## Causes and repairs

| Failure class | Root cause | Repair |
| --- | --- | --- |
| Six direct browser tests | Temporary test configuration did not locate the existing repository browser; user-cache Chromium launch failed with `spawn EPERM`. | An autouse fixture selects the repository Playwright installation only when no explicit `PLAYWRIGHT_BROWSERS_PATH` override exists. Removed duplicate per-test selections. No downloads, production profile changes, or browser security flag changes. |
| Two combobox failures exposed after launch repair | An empty listbox retained dimensions and was classified as open. | Inspect visible selectable options and affirmative collapse/hidden-menu evidence. Exact commitment and valid controls remain required. Also verify closure and validity after the existing selected-option readback path. |
| SmartRecruiters City fixture | Click did not open the menu; `aria-expanded` remained false even when options appeared. | Model a click/search-to-open widget with an owned listbox and truthful open/closed state. No claim about live SmartRecruiters behavior or typing-first support. |
| SmartRecruiters two-step engine | Earlier-step control receipts survived replacement of the control inventory. | Retire control receipts only after a stable observed, security-checked transition. Preserve independently accepted same-session attachments and saved answers/provenance. Same-step rediscovery retains receipts; missing controls explicitly fail validation. |
| Retirement test | An incomplete `Engine.__new__` instance lacked `fill_only`. | Construct a real Engine with isolated config and controlled dependencies; assert no database/application/browser processing occurs and retain the final-interaction retirement assertion. |
| Mapper conflict | `UNKNOWN_FIELD` conflated no mapping with conflicting evidence; legacy label fallback supplied an email anyway. | Use `REJECTED_FIELD` for conflicting evidence before cache/provider fallback. Resolver permits exact scoped verified answers, otherwise abstains before weaker rules. `UNKNOWN_FIELD` keeps legacy compatibility. Rejected fields are not eligible for generated prose. |
